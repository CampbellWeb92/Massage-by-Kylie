MASSAGE BY KYLIE — STATIC WEBSITE
=================================

FILES
-----
index.html
style.css
script.js
images/logo.svg

HOW TO USE
----------
1. Unzip the folder.
2. Open index.html in your browser to preview the website.
3. Upload index.html, style.css, script.js and the images folder to your web host.
4. Keep the same folder structure.

FEATURES INCLUDED
-----------------
- Responsive desktop, tablet and mobile design
- Black, white, silver and red colour scheme
- Elegant typography
- 18+ age-verification popup
- Sticky navigation
- Mobile hamburger menu
- Responsive services and rates
- Gallery slider
- WhatsApp / phone / email links
- Google Maps location link
- Simple editable SVG rose logo
- Scroll reveal effects
- No framework required

EDITING
-------
Most text is inside index.html.
Colours are defined near the top of style.css under :root.
The logo is images/logo.svg and can be edited as text/XML.
The age popup logic and mobile menu are in script.js.

IMPORTANT
---------
The current version uses abstract CSS artwork instead of embedded third-party photographs,
so the ZIP remains lightweight, self-contained and copyright-safe.

To use your own photographs:
1. Put them in the images folder.
2. Replace the .service-image backgrounds in style.css or add <img> tags in index.html.

LIVE BUSINESS HOURS REPAIR
--------------------------
Fixed the live-hours status after the compact redesign.

Cause:
The compact layout removed the businessLocalTime element, but script.js still
required that element before it would update the business status. This caused:
- "Checking hours…"
- Today's hours "—"
- "Checking the current local time…"
to remain on screen indefinitely.

Fix:
- Current status now updates even if optional layout elements are missing.
- Re-added a compact Johannesburg-time display.
- Added a safe fallback if timezone calculation ever fails.
- Live status updates immediately and refreshes every 60 seconds.
